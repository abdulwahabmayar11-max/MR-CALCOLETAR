# Oxygen Calculator
A lightweight Android calculator with a dark OxygenOS-inspired interface.

## Build APK on GitHub using a phone
1. Create a GitHub repository named `OxygenCalculator`.
2. Upload the contents of this folder (not the outer folder itself) to the repository. Keep `.github/workflows/build-apk.yml` in place.
3. Open the repository's **Actions** tab and choose **Build Oxygen Calculator APK** if it has not started automatically.
4. Open the successful run and download the **Oxygen-Calculator-APK** artifact. Extract the ZIP and install `app-debug.apk` on your Android phone.

This is an independent calculator inspired by OxygenOS styling, not the official OnePlus system app.
